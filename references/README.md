# Visual References

Reference snapshots preserve the visual evidence that shaped Rizum Glass. They are intentionally non-canonical.

## Included Snapshots

- `nolnol-ui-prototype-v14.2.html` is a broad product-specific prototype containing compact panels, menus, dialogue, settings, editorial surfaces, cards, onboarding, asset management, and other experiments.
- `icons/game-icon-pack/` contains the icon subset used by that snapshot, sourced from [Nieobie/Game-Icon-Pack](https://github.com/Nieobie/Game-Icon-Pack) and stored with its upstream license.

The prototype loads Tailwind from a CDN and needs internet access for complete rendering. Its game-icon paths remain relative to this directory.

## How To Use References

1. Read `../DESIGN.md` first.
2. Use the snapshot to inspect material, density, motion, and component relationships.
3. Generalize any useful lesson before adding it to the canonical guide.
4. Do not copy product labels, feature names, information architecture, or screen flows into an unrelated project.
5. Add a new versioned snapshot when the reference evolves. Never overwrite this file.

The reference can contradict a newer canonical rule because it records a moment in the design process. In that case, `DESIGN.md` wins.
