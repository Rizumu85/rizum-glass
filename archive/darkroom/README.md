# Archived Darkroom Transfer Tests

This directory preserves the retired darkroom transfer-test series. It is historical validation evidence, not an active visual reference or starter template.

- `transfer-test-darkroom-v12.html` is the original light transfer test.
- `transfer-test-darkroom-dark-v1.html` through `v6.html` record dark appearance and cursor-lighting experiments.
- `transfer-test-darkroom-dark-v7.html` is the final approved dark appearance: solid `#111113` canvas, neutral dark glass, and no cursor-following light.

The reusable dark rules have been promoted into `../../DESIGN.md` and generated adapters. Use `../../references/rizum-glass-ui-gallery-dark-v11.html` as the active dark visual reference.
